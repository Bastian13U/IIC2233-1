# IIC2233 - Programación Avanzada

Repositorio personal donde subo mis avances, tareas y actividades del curso **IIC2233 - Programación Avanzada**, dictado en la Pontificia Universidad Católica de Chile.

## 📚 Sobre el curso

IIC2233 es el curso de programación avanzada de la carrera, enfocado en:

- Programación orientada a objetos (POO)
- Estructuras de datos y algoritmos
- Concurrencia (threads, procesos)
- Programación de interfaces gráficas
- Redes y sockets
- Manejo de excepciones y buenas prácticas de diseño

## 📁 Estructura del repositorio

```
IIC2233-1/

│   ├── tarea-1/
```

> Ajusta esta estructura según cómo realmente estén organizadas tus carpetas.

## 🛠️ Tecnologías

- **Python 3.x**
- Librerías puntuales según cada tarea (por ejemplo `PyQt`/`PySide` para interfaces gráficas, `socket` para redes, `threading`/`multiprocessing` para concurrencia)

## 🚀 Cómo ejecutar

Cada tarea o actividad tiene su propio punto de entrada. En general:

```bash
cd tareas/tarea-X
python main.py
```

Revisa el `README` o enunciado específico de cada carpeta si requiere instalar dependencias (`pip install -r requirements.txt`).
